# Vice City Cover Maker

Turn your own photo into striking GTA-style cover art: a multi-panel poster with bold Anton caption lettering, a Pacifico script accent, and a sunset or neon colour grade — exported as a PNG to share.

Upload a photo (or try a sample), crop and position it across several panels, edit the caption, pick a layout (Hero, Duo, Trio, Grid) and a grade (Sunset, Neon Nights, Vice Pastel), then export in one click at 1080 × 1080, 1080 × 1350, or 1920 × 1080. The app is plain static files under `app/` — it runs offline in a desktop browser, photos never leave your machine, and it uses no Rockstar logo, artwork, or fonts (lettering is Anton + Pacifico, SIL Open Font License).

Try it locally: `node serve.ts`, then open http://localhost:8080.
